          Palabras que aparecen aquí
          
    
            
    Valor crudo
    El número tal como sale del sensor, de 0 a 4095. Más alto = tierra más seca.
    
            
    Humedad %
    El valor crudo convertido a algo fácil de entender: 0 % es tierra seca, 100 % es tierra empapada. La placa descarta los decimales (37,9 queda en 37).
    
            
    Equivalencias
    
            
    Límite (umbral)
    Un número fijo con el que se compara. Aquí hay dos: 35 % para empezar a regar y 50 % para dejar de regar.
    
            
    Modo riego
    Se activa cuando la tierra está seca y se apaga cuando ya tiene suficiente agua. Entre los dos límites se queda como estaba: si venía regando sigue regando, y si no venía regando no riega.
    
            
    Pulso
    Un riego corto: la bomba se enciende 3 segundos (unos 75 ml) y después espera antes de volver a medir.
    
            
    Relé
    Un interruptor que la placa puede accionar. La placa no da suficiente corriente para la bomba; el relé la deja pasar desde la fuente.
